# JPComedy 進階操作

第一次使用先看 [README](../README.md)。以下指令在專案資料夾中執行，並假設 `.env` 已設定。

## 指定影片與提示

```bash
.venv/bin/python main.py "影片網址或本機檔案路徑" "節目名稱、出場組合與特殊譯名" --refine --glossary-check
```

這是進階入口，會直接執行、使用服務額度；需要每次費用提醒請用 `jpcomedy.py`。

## 先試短片段

```bash
.venv/bin/python main.py "影片網址" --to 120 --refine --glossary-check
```

會先下载完整影片，再在本機截取前兩分鐘。相同影片的已處理專案會沿用舊進度；已完成影片不會因為加上 `--to` 而重新切割。正式全片請使用獨立專案／獨立工作目錄，保留試跑產物。需要中斷在某階段，可查看 `main.py --help` 中的 `--break-after`。

## 字幕樣式與預覽

預設從 `preferences.json` 讀取；`preferences.local.json` 可覆寫個人偏好。字幕字級、下方位置、上移位置都以 1920×1080 為座標。

```bash
.venv/bin/python -m services.subtitle_burnin "projects/影片ID" --ranges "字卡時段.json" --preview 30
.venv/bin/python -m services.subtitle_burnin "projects/影片ID" --ranges "字卡時段.json"
```

時段 JSON 為 `[[12, 18], [30, 40]]`，也接受 `{"ranges": [[12, 18]]}`。每次輸出到新的 `.burnin/編號/`，會保留 ASS、預覽圖或燒錄影片。未提供時段時都放下方。範圍資料可由人工標註或外部 OCR 產生，但本入口尚未整合自動 OCR。

## Podcast

準備一個已完成字幕的專案，包含 `video.cht.finalized.srt`、`poster.jpg`（也接受 PNG 等），以及 `podcast_source.mp3` 或原始 `video.mp4`。

```bash
.venv/bin/python -m services.podcast_video --project-dir "projects/影片ID" --title-zh "本集中文名稱"
```

會輸出黑底影片，封面佔左側 1/3，字幕在右側 2/3；並放到 `成品/本集中文名稱/`，另附外掛字幕。音檔取得、轉錄、翻譯需先完成。FFmpeg 需含 libass；Pillow 備援渲染需額外安裝 `uv pip install pillow`，備援字型搜尋目前以 macOS 為主。

## 共用詞庫與個人詞庫

`.env` 的 `GLOSSARY_REMOTE_REPO=allen365apple/jpcomedy-glossary` 指向共用來源。每個專案的 `.glossary/snapshot.json` 保存資料、commit、checksum 與時間；之後續跑沿用，不能靠更新全域 JSON 改變既有專案的用詞。

離線時優先使用 `.glossary-cache/` 最近的有效版本；沒有快取則使用專案內的詞庫並記錄來源。遠端格式不合法也不會覆蓋最後有效快取。

若只想用本機詞庫，設定 `GLOSSARY_REMOTE_REPO=`，並執行：

```bash
.venv/bin/python -m glossary_ui.server
```

這個介面只會儲存本機 JSON。雲端版則從獨立 repository 讀取／儲存，兩者不會偷偷互相覆蓋。

## 升級工具

先保存自己的修改，再 `git pull --ff-only`，接著 `uv sync`。若 Git 顯示有衝突，請保留檔案並請熟悉 Git 的夥伴協助，不要使用強制覆蓋。一般的共享詞庫更新不需要更新整套工具。

## 給維護程式的夥伴

```bash
uv run --with pytest python -m pytest
cd glossary_cloud
npm ci
npm test
npm run check
```

翻譯流程保留原作的續跑設計；新增功能以小模組接入，方便日後整合原作者的更新。
