# 藝人「詳細介紹」蒐集與撰寫規範

本文件規範日式搞笑大補帖人物頁中「詳細介紹」的研究流程與內容品質。適用於漫才組合、單人藝人、短劇團體及其他搞笑表演者。人物頁若保留《每週漫才》的原文，該區塊仍標示「每週漫才是這樣寫的」；本規範所寫的「詳細介紹」是本站另外蒐集、查證並以繁體中文整理的內容，不取代原文，也不冒充原作者觀點。

## 一、介紹的目的與呈現方式

詳細介紹要讓不熟悉日本搞笑的台灣讀者看完後，同時理解兩件事：這位藝人／組合在日本搞笑界扮演什麼角色、為什麼值得認識；以及他們的表演如何運作、漫才之外還有哪些代表性作品。**「在日本搞笑界的地位與角色」是每篇介紹的必要主軸，不可只列在獎項或基本資料裡帶過。**介紹不是履歷重複，也不是泛泛的形容詞集合。

建議寫 3–5 段、約 350–650 字；資料較少時寧可短而有據，不為篇幅猜測。每篇都要清楚交代其日本搞笑界定位，再依資料狀況涵蓋：

1. **在日本搞笑界的地位與角色（必寫）**：說明他們屬於哪一個世代／發展階段，在日本觀眾或業界脈絡中為何重要。可辨識為漫才史上的先行者、長期第一線的資深代表、某世代的標誌人物、獎賽出身後跨入主流電視／演藝圈的核心人物、地方／寄席文化的重要力量，或近年崛起的新秀等；不必硬塞進單一標籤，要寫清楚其具體角色。對單人藝人也要說明其在搞笑表演、綜藝、戲劇／編劇等領域的定位。
2. **地位判斷的證據與尺度**：用可查證的職涯脈絡支持定位，例如長期代表性節目、持續劇場活動、重要獎項／賽事歷程、協會或組織職務、對後輩的影響、跨媒體創作及本人／同業談及的影響。單一獎項、年齡、知名度或主觀形容不能單獨等同於「地位高」。分清「前輩」「大師」「國民級」「革新者」「新秀」等評價是官方事實、媒體描述、本人說法或本站的編輯整理；若證據不足，就用保守而具體的描述，不做排行榜或無根據封號。
3. **表演形式與題材**：漫談式／短劇式／單人表演等形式；常從什麼情境、人物、語言或生活素材開始。
4. **笑點的推進方式**：前提如何建立、偏差／誤解／妄想如何累積、吐槽或搭檔反應如何改變方向、重複與停頓如何形成節奏，以及包袱如何回收。只描述來源支持的具體特徵，不把個人推論寫成藝人自述。
5. **藝人自己的說法**：優先找本人專訪、創作談、節目製作訪談或舞台談話。說明「誰在什麼訪談中談到什麼」，以繁中忠實轉述；短引文才加引號，不能把轉述包裝成逐字引言。
6. **其他演出與作品**：補充官方頻道、冠名／固定節目、廣播、Podcast、單獨公演、短劇、戲劇／電影編劇或出版等。不能只列名稱；至少挑一至數項有代表性的作品，交代節目／公演的實際形式與內容、藝人在其中負責什麼，以及它如何呈現其表演特色。可用官方節目簡介、單集介紹或製作訪談具體說明企劃如何進行、來賓／觀眾如何參與、主題如何變化。區分現正播出、已完結、單次特別節目與單次來賓，不可把來賓演出寫成自主持節目。若只有名稱或查不到內容，就明確縮小介紹範圍，不得自行推測。
7. **組合互動**：如為組合，說明成員如何分工、是否互換角色、彼此的反應如何成為笑點；不可只列「裝傻／吐槽」標籤。

## 二、搜尋流程：以日文為主，並用近義詞交叉查找

不得只用中文搜尋。每位藝人至少以日文姓名／團體名搭配多組不同概念查詢；藝名、漢字、假名、常見簡稱與英字寫法可交替使用。不要只查同一組關鍵字或只看搜尋摘要。

### A. 基本資料與官方作品

先查所屬事務所、官方藝人頁、主辦單位、電視台、電台、出版社或作品官網。可用下列組合，再依藝人實際狀況替換：

- `藝人名 プロフィール 公式 所属 結成`、`藝人名 経歴 公式`、`藝人名 賞歴 公式`
- `藝人名 レギュラー番組`、`藝人名 冠番組`、`藝人名 出演番組 公式`
- `藝人名 ラジオ パーソナリティ 公式`、`藝人名 冠ラジオ`、`藝人名 ポッドキャスト Podcast`
- `藝人名 単独ライブ 公演 ネタ`、`藝人名 DVD 配信 公式`、`藝人名 著書 原作 脚本`

節目名稱常以近義用語發布，應交叉查找：`冠番組`／`冠番組を持つ`、`レギュラー`／`レギュラー出演`、`パーソナリティ`／`冠ラジオ`、`ラジオ`／`音声番組`／`Podcast`／`ポッドキャスト`／`配信`。如查新節目，再加上 `新番組`、`放送開始`、`配信開始`、`終了`、`最終回` 及年份，避免把舊資料誤當現況。

### B. 漫才／短劇風格與笑點分析

至少用數組不同日文說法搜尋，不要預設每個藝人都會被稱作同一種風格：

- `藝人名 漫才 特徴`、`芸風`、`漫才スタイル`、`ネタの特徴`
- `藝人名 ネタ分析`、`ネタ解説`、`漫才 考察`、`コント 分析`
- `藝人名 ボケ ツッコミ 役割`、`掛け合い`、`間`、`テンポ`
- `藝人名 ネタ作り`、`創作`、`台本`、`発想`、`作り方`
- 以已知段子題材或招牌梗替換通用詞，再搜尋 `どこが面白い`、`構造`、`オチ`、`伏線`、`言葉遊び`

不要只搜抽象的「漫才 風格」。將團名加上不同近義詞、具體段子名、代表節目名，以及成員姓名再查一次；一個詞查不到時，改用另一種寫法或相關表達繼續找。研究文章中的分類是作者分析，不要逕自說成日本業界的官方分類。

### C. 專訪與藝人本人的說法

優先找本人直接受訪，而不只是第三方簡介：

- `藝人名 インタビュー 漫才`、`単独インタビュー`、`ロングインタビュー`
- `藝人名 ネタ作り インタビュー`、`芸風 きっかけ`、`本人が語る`
- `藝人名 対談`、`創作秘話`、`ライブ インタビュー`、`番組 インタビュー`
- 加上媒體／官方網域，如 `site:natalie.mu/owarai`、`site:oricon.co.jp`、`site:thetv.jp`、所屬事務所網域、電視台／電台網域。

閱讀正文確認受訪者、訪談日期、上下文和原意。不要只根據標題或搜尋摘要寫「他曾說」。訪談若只談人生經歷，不能硬解讀成對段子技法的說明。

### D. 日本搞笑界地位、世代與影響力

每位藝人都要使用日文查找其職涯位置，而非由本站作者憑印象判定。可交叉使用：

- `藝人名 お笑い界 位置づけ`、`芸人としての立ち位置`、`お笑い界 影響`、`代表的 芸人`
- `藝人名 世代 先輩 後輩`、`芸人 仲間 評価`、`後輩に影響`、`漫才界 功績`
- `藝人名 テレビ界 活躍`、`冠番組 長寿番組`、`劇場 支える`、`協会 会長 理事`
- `藝人名 賞歴 M-1 優勝`、歷屆官方成績、所屬事務所正式履歷及主流節目／公演官方紀錄

寫作時要讓台灣讀者知道「重要在哪裡」，而非只下「大前輩」「傳奇」「國民級」等結論。可以說明某組合是第一屆大型漫才賽事的冠軍、曾長期代表一種舞台路線，或其成員後來成為節目主持／創作者／組織領導者；也可以說某組合是近年賽事崛起的新秀，但需連結可查證的事實。用具體的年代、作品、職務、成績與當事者／同業訪談來支撐判斷，並避免把「年紀較長」直接寫成「地位較高」。

可採用較描述性的定位句型，例如：「在 2000 年代漫才賽事中建立代表性，之後仍以劇場與電視活動維持第一線」、「從地方劇場／寄席出發，成為該舞台文化的主要代表之一」、「以個人短劇建立聲望，並進一步成為戲劇編劇與節目創作者」、「近年透過大型賽事進入主流視野的新世代組合」。這些是寫作句型，不是預設分類；須逐人查證後再選用。

## 三、來源判準與查核紀錄

來源優先順序：

1. **一手／官方來源**：所屬事務所、藝人官方頻道、電視台／電台節目頁、主辦單位、作品官網、出版社、正式新聞稿。用於查姓名、職務、結成年、官方作品名稱、播出／發行資訊與現況。
2. **本人專訪或節目製作訪談**：本人對漫才、創作、搭檔、作品的說法；或製作人說明節目設計。必須清楚標註受訪者，不將製作人的評價改寫成藝人自己的話。
3. **可靠媒體與研究**：以日文撰寫、來源清楚、有作者／採訪脈絡的新聞媒體、文化刊物或學術研究。適合補足笑點機制與時代背景。
4. **二手整理／社群**：只作為發現線索，不作重要事實的唯一依據。百科、未署名部落格、論壇、短影音字幕及搜尋摘要不可單獨支持介紹中的事實。

每一項可核實的關鍵事實都要能對到來源：誰負責創作、節目是否仍播出、作品職務、獎項年份等尤其如此。來源彼此矛盾時，優先採用最新官方資料或直接當事者資料；無法判定就刪去精確說法，或在資料中註明不確定，不要自行調和。

每篇 `researchedArticle.sources` 至少列 2 個實際讀過且直接支持內容的來源；若現存可靠資料不足，可少寫內容並說明範圍，不可湊入不相關連結。來源標籤用繁體中文描述媒體與內容，例如「ORICON：藝人談即興創作」，不要只寫「資料來源」。保留原始 URL，不以搜尋結果頁代替文章頁。

## 四、繁體中文翻譯規則

- 介紹正文以台灣繁體中文撰寫。節目名、單獨公演名、書名、戲劇／電影名及漫才術語第一次出現時，先給清楚的中文譯名，再以括號附日文原名，方便讀者理解和回查。例如：`錯位漫才（ズレ漫才）`、`《奧黛麗的 All Night Nippon 深夜廣播》（オードリーのオールナイトニッポン）`。即使官方品牌使用英文或日文羅馬字，也須附上中文意義或節目類型，不可只把原名換成羅馬字就當作已翻譯。
- 這條規則也適用於頁面上可見的資料欄位，不只詳細介紹正文：`works[].title`、`videoResources.title`、代表經歷中的節目／賽事名稱，以及參考來源標籤內提到的節目名，都要先呈現中文譯名，再保留官方原名供查找。官方頻道或藝人本名等專有品牌可保留原名，但要用中文清楚標明它是官方頻道、單集影片或其他影音資源。
- 若節目名是自創詞、諧音或沒有穩定中文譯名，不要硬造看似官方的譯名；以中文說明其節目類型或可理解的意譯，並明確保留日文原名。
- 英文品牌或官方固定名稱可保留英文，但若標題／日文文案帶有可譯含義，補中文說明，例如 `《THE ONE SHOT》（一擊制勝）`。不得把有意義的日文只原樣貼在中文句中，或只用羅馬拼音代替翻譯。
- 同一段落再次出現可用中文簡稱；若文章較長、隔了數段或存在同名歧義，重新附原文。不要每句重複全名造成閱讀負擔。
- 漫才術語使用精確、自然的台灣用語，例如「裝傻（ボケ）」「吐槽（ツッコミ）」「談話型漫才（しゃべくり漫才）」「短劇式漫才（漫才コント）」。說明不同藝人或媒體的稱法可能不一致時，保留原詞並解釋差異。
- 人名、團體名、事務所名依網站詞庫與人物頁命名規則；不要為了翻譯而改動官方姓名。外國藝人、地名或文化專有名詞第一次出現時，視理解需要補原文或簡短釋義。
- 翻譯是摘要與轉述，不整段複製原文。直接引語只保留必要短句並註明受訪者和來源；其餘用自己的中文概括。

## 五、文章建議結構

可依資料多寡調整，不必硬套小標：

1. **開頭自然交代日本搞笑界的位置**：把其世代、角色與重要性寫成詳細介紹的第一段，直接接入正文，不另設「在日本搞笑界的位置」小標或獨立資訊區塊。根據個別事實描述其為資深代表、早期賽事冠軍、劇場／寄席傳承者、節目主持／創作者、某世代代表或新秀等；不可所有人都套同一種「大前輩」模板，也不可只憑年齡、單一獎項或作者印象定高低。
2. 接著交代表演形式與辨識度最高的素材，拆解一個有來源支持的笑點運作例子：前提、偏差如何推進、搭檔如何接話／反應、最後如何變成包袱；避免自行編造台詞。
3. 整理專訪中的本人說法，說明它如何幫助理解創作、職涯或同行位置；用「在某年某媒體專訪中，X 回憶／提到……」等可追溯敘述。
4. 簡介有代表性的其他節目、廣播、個人企劃或作品，解釋內容、格式及藝人角色。作品也可用來說明其演藝圈位置如何從漫才延伸；不重複獎項清單，不把作品標題當內容介紹。
5. 組合頁補充成員互動與角色變化。結尾可點出其職涯承接的傳統、帶來的變化，或在新世代中的位置；有可靠材料才寫。

## 六、資料寫入與驗收清單

在 `content/profiles.json` 對應藝人新增 `researchedArticle`，欄位格式依 `PROFILES_SCHEMA.md`。將日本搞笑界定位寫入 `researchedArticle.positioning`，日文查證來源放在 `positioningSources`；網站會把定位段直接排在詳細介紹正文開頭，與風格、專訪和作品內容連續呈現，不顯示獨立定位區塊。寫完後逐項確認：

- [ ] 日文搜尋涵蓋基本資料、漫才／搞笑風格、本人專訪、代表節目／作品，並用同義詞或近似說法交叉查找。
- [ ] 至少讀過兩篇可直接支持內容的日文來源；重要事實有官方或當事人來源。
- [ ] 寫出具體笑點結構與成員互動，不只使用「有趣」「節奏快」「很有特色」等空泛詞。
- [ ] 至少提及可查證的專訪說法，清楚區分本人、記者、研究者與製作人的觀點。
- [ ] 開頭清楚交代藝人在日本搞笑界／演藝圈的地位、世代與角色，至少以兩種可查證線索支持，且不以年齡或單一獎項直接推導地位。
- [ ] `positioning` 是詳細介紹的第一段，與正文連續閱讀、不另加小標或獨立區塊；附上直接支持該段的日文來源連結，定位具體、可理解，不誇大、不硬排名。
- [ ] 至少一項代表節目／作品有「內容說明」而非只有名稱：交代節目形式、企劃／主題內容、藝人職務；已確認官方名稱、連結與播出狀態。
- [ ] 日文節目名、作品名與術語都已中文化；正文、作品欄位、官方影音標題及代表經歷的首次出現處皆先列中文、再附原名。
- [ ] 文章不是逐字翻譯或大段摘錄；來源連結緊鄰其支持的內容。
- [ ] 有《每週漫才》原文的藝人仍顯示原有區塊；不要把它改名或覆蓋成「詳細介紹」。
- [ ] 本次「詳細介紹」補寫只套用在沒有《每週漫才》原文的藝人頁；有原文者不覆蓋、不改寫其原文。
- [ ] `npm run build` 與 `npm test` 通過，頁面來源連結可開啟。

完成後更新 `ARTIST_BACKLOG.md` 的狀態、查核日期與尚待確認項目。只新增或修改資料，不刪除使用者既有檔案。
