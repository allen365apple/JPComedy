# 首頁與圖片載入改善

2026-10-03：無 Chrome DevTools MCP，因此沒有宣稱 Core Web Vitals 或實際使用者時間評分。以下為建置檔案大小與功能驗證結果。

- 原初始資料 1,972,118 bytes，包含 265 位完整介紹；改讀約 358 KB 搜尋目錄，降低約 82%。完整介紹按頁面需要下載，沒有刪減內容。
- 265 張藝人卡片原始主圖總計約 31.4 MB；480px WebP 合計約 4.1 MB，減少約 87%。這是整批圖片大小，不代表首頁一次下載全部圖片。
- 首頁主圖與目錄預載；卡片依螢幕選擇 480／960px，非首屏延遲載入；詞庫程式延後載入。
- 介紹檔案以內容雜湊命名，同一分頁快取成功的請求；失敗不永久快取，快速切換頁面不覆蓋新路由。
- 原圖不修改、不裁切、不刪除，圖片來源與文章授權標示保留；正式詞庫沒有寫入。
- 22 項單元測試通過，公開產物檢查會比對每份分拆介紹與完整資料相同；瀏覽器確認首頁、原文介紹和返回導航，無 console error。
- npm audit：Sharp 0.35.5，沒有已知漏洞；CI 使用 npm ci 鎖定依賴版本。
