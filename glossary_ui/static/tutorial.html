先記住三件事

  1. API Key 是秘密，不要貼到群組。
  2. 語音辨識和翻譯可能會消耗額度。
  3. AI 翻完一定要人工檢查。

從零開始

你不需要會寫程式

只要先把工具安裝好，接著雙擊啟動檔、貼上影片網址，JPComedy 就會幫你產生繁體中文字幕，並可選擇燒進影片。

第 1 步｜準備 ElevenLabs

申請帳號並取得 API Key

ElevenLabs 負責「聽懂日文、做出字幕時間軸」。它不是本專案的帳號，請使用你自己的帳號與額度。

  1. 打開 ElevenLabs 註冊頁，建立帳號並登入。
  2. 進入 API Keys 設定頁；如果頁面改版，也可以看官方說明。
  3. 按「Create API key」或類似按鈕，名稱可以填 JPComedy。
  4. Key 通常只會完整顯示一次，立刻複製；不要貼到 LINE、Slack、GitHub 或公開網頁。
  5. 之後在 JPComedy 的設定畫面貼上，或在終端機執行 jpcomedy.py --setup 時貼上。

ElevenLabs 的 API Key 會使用你的帳號額度；請先看當前方案與費用，第一次建議先用短片測試。

第 2 步｜準備翻譯帳號

登入 Codex CLI

Codex 負責把日文字幕翻成繁體中文。安裝後在終端機輸入：

npm install -g @openai/codex
codex login

登入畫面會帶你用自己的 ChatGPT／Codex 帳號完成登入。請看Codex CLI 官方教學。

第 3 步｜Mac

Mac 只要雙擊這個檔案

  1. 從 GitHub 下載 JPComedy，第一次依 README 安裝 Git、uv、Node、FFmpeg。
  2. 完成 uv sync 與 jpcomedy.py --setup。
  3. 雙擊 開始翻譯.command。
  4. 貼上 YouTube、Bilibili、AcFun 網址，或貼本機影片路徑。
  5. 看完費用提醒後輸入 YES，才會開始送出語音辨識與翻譯。

第 3 步｜Windows

Windows 也有一鍵啟動

  1. 安裝 Python、Git、uv 和 Node.js。
  2. 從 FFmpeg 官方下載頁取得 Windows build，解壓縮後把包含 ffmpeg.exe 與 ffprobe.exe 的資料夾加入 PATH。
  3. 在 JPComedy 資料夾按右鍵，選「在終端機開啟」，輸入 uv sync。
  4. 輸入 npm install -g @openai/codex、codex login，再輸入 uv run python jpcomedy.py --setup。
  5. 之後雙擊 開始翻譯.bat；也可以右鍵用 PowerShell 執行 開始翻譯.ps1。

如果 Windows 跳出「未知的發行者」，請確認檔案確實是從你的 JPComedy 資料夾啟動；遇到錯誤可先執行 uv run python jpcomedy.py --check。

第 4 步｜找成果

字幕和影片會放在哪裡？

每支影片都會放在專案內的 projects 資料夾。你會看到：

  • video.cht.finalized.srt：繁體中文字幕檔。
  • video.cht.ass：帶字幕樣式的檔案。
  • .burnin/.../video.cht.blackbox.mp4：已把黑底字幕燒進去的影片。

翻譯完成後請人工檢查人名、雙關語、日文大字卡與字幕位置；確認後再分享。

共用詞庫

不用 GitHub 帳號也能幫忙修改

打開詞庫網頁後，先編輯畫面上的詞，再向柏文取得共用編輯密碼，輸入後按「解鎖編輯功能」，最後按右上角「儲存所有變更」。密碼不會顯示在網址，也不會保存到你的瀏覽器。

如果只是想提供建議、不確定譯名，請按「匯出草稿」或「提出詞庫建議」，不要直接亂改。

還有問題？

先把錯誤畫面截圖

請把終端機最後 20 行和你使用的作業系統告訴柏文。不要把 ElevenLabs API Key、共用詞庫密碼或其他秘密一起截圖。
